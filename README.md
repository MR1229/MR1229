## How I Approach Learning

- I learn concepts by building something with them, not just reading about them
- I'd rather have a working (if rough) version of an idea than a perfect plan for one
- When something breaks, I treat it as the actual lesson, not an interruption to it
- I revisit fundamentals often — DSA especially — instead of assuming I've "finished" them
- I'm comfortable not knowing something yet, as long as I'm working toward knowing it
